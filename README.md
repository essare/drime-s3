# drime-s3

This repository hosts **drime-s3**, a Bun-powered TypeScript gateway that exposes an AWS S3–compatible HTTP API in front of [Drime Cloud](https://drime.cloud). Buckets are **top-level folders inside a dedicated Drime workspace** (default name `drime-s3`), created with `POST /workspace` and discovered with `GET /me/workspaces` — see the design doc. The full design and roadmap are in [docs/superpowers/specs/2026-05-09-drime-s3-typescript-port-design.md](docs/superpowers/specs/2026-05-09-drime-s3-typescript-port-design.md). Install with `bun install`, then run `bun run dev` (scaffold CLI until the gateway is wired).
